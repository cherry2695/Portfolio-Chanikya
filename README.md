## 👨‍💻 About

This is my personal developer portfolio built to showcase my technical skills, projects, achievements, certifications, and experience.

The portfolio features a modern responsive interface with smooth animations and a backend-powered contact system.

---

## ✨ Features

* Responsive and modern portfolio design
* Interactive animations and smooth transitions
* Projects and technical skills showcase
* Achievements and certifications section
* Education and professional experience
* Resume access
* Contact form with backend integration
* MongoDB integration for portfolio and contact data
* Email notifications using Nodemailer
* REST API for portfolio data
